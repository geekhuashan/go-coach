# 围棋成长徽章

云端练习沿用原家庭登录、每位学习者独立档案、教材顺序和首次作答记录。成长方法为 `family-go-growth-v1`，由现有证据只读计算，不建立奖励数据库，不更改 XP、评级或原作答。Python 本地版继续原学习统计，未提供云端徽章投影时不显示虚构数值。

## 只奖励可核对的学习积累

“不同棋型”按初始棋盘、先手和真实边界核对，合并整盘旋转、镜像、基础家族与已退役的同核心变体。同一棋型最早记录必须为首次无帮助正确；提示、查看气、演示、悔棋、重试以及首错后换旋转题，不会变成新的独立证据。完整变化或判断题保存成功后才有完成庆祝，落子过程和未定走法不冒充做对。

| 徽章 | 条件 |
| --- | --- |
| 自己想出来啦 | 首次独立完成 1 个不同棋型 |
| 棋型小脚印 | 累计首次独立完成 5、10、25、50 个不同棋型 |
| 某知识点在进步 | 同一知识点至少 5 个不同棋型，分布在至少 3 个学习日期 |
| 会想不同的办法啦 | 至少 3 个知识点各完成 2 个不同棋型，分布在至少 2 个学习日期 |

徽章具有档案内稳定 ID、实际证据日期和获得原因。时间缺失或矛盾时保守处理，不补造获得日期。已完成后的其他失误不撤回原里程碑；题库纠错时会按修正后的证据重新核对。学习积累不等于正式围棋段位，本次不把 XP 换算成未经校准的能力百分比。

## 动效和记录

完整做对一题后，小伙伴短暂跳起、挥手；本次真正新增徽章时举章并出现短烟花。下一题按钮保持可用，动画不阻塞落子，不自动请求 AI 或播放声音，不使用覆盖棋盘的弹窗。普通轮询、刷新、档案切换、复盘与继续对局不自动领奖。

“学习记录”保留徽章收藏，默认显示 4 枚，其余展开查看；可查看原因和日期，并点击重播。系统开启减少动态效果时保持静态。退出家庭登录会清除页面中的私密成长内容。所有图形在本地绘制，不请求外部素材。

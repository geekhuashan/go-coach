# 一手一懂 · 围棋练习室

这个项目最初是家长为女儿学习围棋而提出，并与 Codex 协作开发的工具，希望让初学者每走一步都能得到可理解的反馈。项目 ID：`project-go-coach`。

在同一个网页里做题、下棋和看讲解。默认建立“我”和“宝宝”两份独立学习档案，也可添加其他学习者。

## 家庭云端与手机

家庭云端入口：[晞晞的小屋围棋](https://xixi.huashan.app/go/)，需要家庭密码。旧 go.huashan.app 网页入口于 2026-10-14 停用，不保留跳转；原 Worker 仅经晞晞主站私有 GO binding 调用。云端版本采用 Cloudflare Workers + D1，支持家庭登录、每台设备独立选择学习者、PWA 添加到主屏幕与触屏确认落子。学习记录存入 D1；Mac 处理书题后只上传已核对结构，原照片留本地。KataGo 主力跑在 Cloudflare Containers（b10，闲置 10 分钟休眠；休眠时那一手由 VPS 应手，同时唤醒），RackNerd VPS b10 作后备；Mac 关机不影响云端使用。部署、数据迁移和计算服务说明见 [云端部署说明](docs/CLOUD.md)。

家庭学习以三本教材为主线：①手筋专项训练（从入门到10级），目前540题；②手筋专项训练（从10级到5级），前后部分统一为767题；③死活专项训练（从入门到10级），目前528题。按已导入的原题号接续，完成一本后进入下一本。第一本当前仅有第241–780题；第二本第421题因原图答案不清暂未入库，不将缺题声称为完整收录。

棋盘旁提供章节内“上一题 / 下一题”和选题面板：点中间题号打开面板，可先换书、再换章节（每章显示做对几题），最后点题号从任意题开始，已做对的题号带绿色对勾。“上一题 / 下一题”按原书题号前后移动，不跳过已做题、不跨章节；所有练习模式可自选，陪练等待时也可换题。切换本身不计作答或XP。

基础与原创专项按知识点归入第一本的“配套巩固（选做）”，不重复插入教材必做队列；同一基础棋型的旋转版本在选题入口只展示一个代表，旧题号与成绩保留。Go Game Guru 的417道公开每周围棋题放在最后，仅自选进入，保留 David Ormerod、An Younggil 署名及 CC BY-NC-SA 4.0 许可。来源与未激活原因见 [第三方数据说明](docs/THIRD_PARTY_DATA.md)。

日常同步现在先检查小版本号，没有变化时不读取完整棋盘或题库；题库目录有变才重载，完整题目按题号读取。断线时保留当前棋盘；落子回应丢失时先核对服务器状态，不自动重复提交。AI 讲解仅手动点击“请老师讲解”后开始，不随落子、换题、登录或设置加载自动运行；已保存的讲解仍可查看。

## 本地开始

需要 Python 3.10 或更高版本。克隆仓库后，双击 [启动围棋.command](启动围棋.command)，或 `python3 start.py`，打开 <http://127.0.0.1:8769/?v=3>。重启电脑后重新启动即可恢复，没有配置开机自启。

- **练习题**：落子后自动反馈结果、原因与棋盘标记，并保存作答。四类基础知识点，8 个基础局面按难度保留 32 个旋转／镜像版本（一级每类 3 个，二级每类 5 个）；另有 43 个精选原创多手吃子局面，难度 3–5。剔除了旋转、平移或远处加无关棋子的 77 道重复变化，另补 2 道不同计算过程的题，不再给每类凑最低数量；枷吃 3、门吃 5、一线追吃 8、倒扑 6、接不归 4 道。原三道题与精简前的变式继续兼容，已有作答记录和成绩保留。
- **人机对弈**：可选 9 路／19 路、执黑或执白，KataGo自动应手；网页打开时驱动自动应手。悔棋回到自己的上次决策点。
- **双人对弈**：选择 9 路／19 路和黑白两位学习者，在同一棋盘轮流落子；双方都能在对局记录中继续这盘最新棋局。
- **记录**：练习、想法、模型讲解和历史对局分别保存。重试、悔棋、换题不清除学习记录；对局不计入练习成绩。支持历史棋谱SGF导出。

## 页面布局

首页以棋盘为主，只保留当前题目、轮次和常用落子操作。「菜单」展开学习者、练习/对弈模式及题库、学习记录、设置入口；「讲解」打开当前反馈、参考解法、AI 答疑与下一题建议；点空位落子，点已有棋子即时查看气，无需切换工具；默认直接落子，也可在「棋盘选项」开启落子确认。「棋盘选项」保留全盘切换、落子确认等设置。作答后的简短反馈与下一题按钮留在棋盘附近，讲解不自动滚动打断落子。抽屉关闭后回到棋盘；开始选题或继续历史对局也自动回到棋盘。

iPad Air 2 等横屏平板采用左侧大棋盘、右侧题目与操作区，棋盘随浏览器可用高度调整。当前反馈可直接在右侧读完，展开设置和长讲解只滚动操作区；竖屏与手机仍按题目、棋盘、操作排列。保留 19 路局部放大与滚动，确认落子面板会自动进入可见区域。

练习方式按学习者分别保存。家庭已导入教材时，推荐与「按教材顺序」均优先三本书的主线，书内按原题号而不是难度重排，章末接续下一章、完成一本后进入下一本；手选后面的书可继续该书。第二本原先因书名空格/括号而分开的两部分已合并，第264题接第265题。三书完成后停止自动安排，配套巩固和 Go Game Guru 可自选；主动进入 Go Game Guru 后继续该套补充题。没有导入三本教材的本地安装仍沿用原入门课程和推荐逻辑。错题复习保留原记录，重练通过即从待复习中移出。完整做对即可通关，提示后完成不增加独立答题积分；复习模式保留还没做对的题。19 路局部题默认放大题目所在区域，保留真实坐标和边界提示，可随时切回全盘。走出参考答案后，网页会立即核对实际提子和作者明确反驳；两者都不能判定时先保存落子、进入 KataGo 续弈，不让对手应手等待重型比较。点「重新复核」才会让 KataGo 比较你的落点与参考点，优先使用快速通道、失败后只回退一次；也可「看参考解法」逐手查看后重练。

实战棋盘和「学习记录 → 我的对局」提供「回看基本棋型」。网页在后台线程按棋谱重放，检查本人最近 120 手范围内的提子、逃出打吃、打吃、双打吃机会，最多显示 24 个局面。先在落子前的棋盘自己选点，再揭示当时的走法；可进入对应基础题并返回原对局。这里只核对局部规则事实，不把没有选择候选点判成坏棋，不改实战和练习成绩；复杂枷吃、倒扑等尚未自动识别。

## 学习水平与推荐

水平表示入门知识点掌握情况，不是围棋段位。按不同题目的首次独立作答计算证据，少于3题标为待评估。提示、查看气、演示后的作答与重复尝试会留痕，不增加独立掌握证据。

基础题有至少3个不同题号的独立样本且正确率达到75%后，可推荐下一档。吃子题可逐档到难度5；某档不足3题时，以该档全部题目为样本门槛。推荐也会覆盖尚未练习的知识点。基础旋转版本当前仍分别记录作答，界面另列独立局面数；不把这些数量当作段位评估。

题库按“选书 → 章节（带做对进度）→ 题号”直接选题，不要求先通关；配套巩固在章节列表最下面，选做。多手题由你连续落子，程序按收录分支自动应手；重复练习会轮换对手分支。如果走出参考答案，网页保留复核结果并转入续弈：KataGo 会按当前局面自动应手，之后可继续落子、悔棋或停一手，不会因为偏离答案立即锁住棋盘。云端实战应手优先使用低延迟通道，失败才尝试另一条；请求超时或 iPad 从后台恢复时，网页会先同步服务器棋盘，不盲目重放落子。一次短暂失败先显示正在重连，连续失败或系统明确离线才显示连接中断。读请求最多重试一次，并覆盖响应体接收超时；落子请求不会自动重放。题库排序复用比较器，减少服务资源超限。陪练思考或复核期间可以直接换题，旧请求结果不能覆盖新局面。原创吃子答案已验证合法性和实际提子目标；第三方死活题按作者明确标注的正解收录，但不表示穷尽所有防守或唯一最佳着。作者明确反驳按失败记录；KataGo 给出走法评价、参考点和合法试算，模型意见不计入正确率或通关。故障时保存落子并允许重试，规则已确认完成提子目标则可直接通过。详见 [走法复核](docs/LESSON_REVIEW.md)。完成整条变化才记录成绩；悔棋回到自己的决策点，提示、悔棋或中途重练后的完成不冒充首次独立作答。

## 按近期表现安排练习

未导入三本教材的本地基础课程中，智能推荐结合最近 30 条真实作答按题型调整：连续做对 3 道不同题时减少该类出现；连续答错 2 道不同题时优先换题巩固，有较简单题时降低难度；连续练同一类 3 次后穿插其他题。中间的错误或辅助会打断连续正确，反复做同一道题不凑次数；仅仅未被题库收录不当作错误，需有作者明确反驳；AI 的估计不改写独立作答统计。后来练熟后真正连续做对也可减频，首次独立评价与 XP 仍按原口径计算。推荐会说明安排原因；顺序闯关保持固定顺序。

新增 [17 道短变化原创题](data/original-extra/README.md) 包含倒扑、接不归、短征吃各 3 道；全部分支回放验证合法和提子目标，并排除旋转、镜像、平移重复。难度 3 的原创专项由 4 题增加到 21 题，加上 Go Game Guru 的 139 题，共 160 道；题库选择难度时默认展示全部知识点，也可再缩小筛选。

「讲解」中的中文视频默认收起，按相关概念推荐最多 3 条；题库可展开来自 3 位作者的 49 条分集视频目录，支持主题和作者筛选，涵盖数气、打吃、连接分断及常见吃子手法。全部 49 条视频在家庭登录后通过 Cloudflare R2 直接播放；抱吃与挖吃各有 2 条对应视频；后续章节包含有眼杀无眼、延气、滚打包收、金鸡独立等，并按书题的中文章节概念推荐。这些是知识点讲解，不是本书逐题解答；全部保留原作者链接；播放器关闭后回到练习，不占据主棋盘；来源及核对范围见 [视频目录](docs/TEACHING_VIDEOS.md)。

## 拍书题与本地导入

把题图发到 Codex 对话，可附上答案图、书名、页码与题号。识别后先核对棋子、棋盘边界与先手，再录入答案分支并由规则程序回放验证；看不清或无可靠解答的内容先留待核对。当前网页不自动识别照片，也不将照片发给外部服务。已识别书题保留在家庭私有D1，界面分组不改原始来源、答案、题号或学习成绩。

已核对题目可以通过网页“把书上的题放进题库”导入单题 JSON；也可由 Codex 直接调用本地导入接口。导入内容持久保存在 `.local/imported-lessons.json`，所有学习者共用题库，作答仍各自记录。已有题号拒绝覆盖。当前支持 9 路或 19 路吃子及带可靠作者解答来源的题目、黑先或白先、1–31 手答案树；不支持通用死活评分；19 路对弈、摆题、导入和 SGF 导出均支持。云端已导入上述三本书；文字判断/数眼题目前由Cloudflare版处理，Python本地版的该题型能力边界见 [判断题契约](docs/CHOICE_ANSWERS.md)。

JSON 字段及识别核对流程见 [题库导入说明.md](题库导入说明.md)。

## LLM讲解设置

在“AI讲解老师 → AI讲解设置”填写 OpenAI兼容的 Base URL、模型名、API Key。保存后可点击连接测试；勾选启用后，点击“请老师讲解”才会请求讲解，也可以输入问题后手动提问。

LLM只负责中文讲解和辅导，KataGo负责落子。换题、继续落子或复核结果更新时，页面会停止等待上一局面的旧讲解；需要新讲解时再次手动点击，避免旧请求占住当前讲解，不会把旧回答贴到新棋盘。练习反馈由规则程序核对；自由对局讲解可结合KataGo分析。未配置时仍能练习、对弈和获得本地规则反馈。

API调用费用按提供方规则计算。连接测试只发简单问候，不发棋盘。启用讲解会发送匿名棋盘、最近走法、规则事实和学习概况；不自动发送姓名、完整练习历史或已保存的个人想法。主动输入的问题会发送给模型。

本地运行时，密钥保存在本机 `.local/llm-settings.json`，权限0600，不回显、不写入浏览器存储。留空保留旧密钥，更换API地址会清除旧密钥，需要重新填写。默认关闭，没有替用户选择模型服务或填写凭据。模型回答不是规则裁判，复杂判断仍需结合棋盘验证。

## 运行与保存

Python标准库服务、原生HTML/CSS/JavaScript，无网页外部依赖。仅监听127.0.0.1:8769并校验Host/Origin。

KataGo 为可选的独立引擎，不随本仓库分发；未安装时仍可做题和双人对弈。macOS 可先运行 `brew install katago`，其他系统安装后通过下述环境变量指定引擎和模型。当前已验证环境为 macOS，默认使用 `/opt/homebrew/share/katago` 的b18模型。可通过 `GO_COACH_KATAGO`、`GO_COACH_MODEL` 改路径。每次最多64 visits、3秒搜索预算，首次加载另计；棋力较强，未校准初学者段位。

棋局禁止自杀，采用全局同形禁着，停一手豁免。引擎按相同规则贴7.5目分析。双方停一手后结束；本版尚不自动裁定死活、终局数目或胜负。

`.local/profiles.json` 原子保存全部角色与对局。旧 `.local/state.json` 保留，并备份为 `state.pre-profiles.json`；旧局面迁入“我”，不会倒推历史成绩。整个 `.local/` 被Git忽略。可通过 `GO_COACH_DATA_DIR` 使用隔离数据目录测试。

## 教师与开发接口

`python3 coach.py` 读取当前共享局面；`--analyze` 获取KataGo分析；`--action-file` 提交JSON文件。动作必须携带读取到的revision，旧请求409，不能重放覆盖另一角色。

- GET `/api/state`、`/api/lessons`、`/api/history`、`/api/matches`、`/api/sgf`。
- POST `/api/lessons/import`：`{revision, lesson}`，校验后新增本地题目。
- POST `/api/action`：play、pass、undo、retry、next_lesson、practice_mode（mode 为 recommended / sequential / review）、solution、switch_profile、add_profile、new、resume_match；也支持setup、annotate、demo、demo_next、restore_demo。
- POST `/api/analyze`：只读分析，传revision。
- GET/POST `/api/llm/settings`；POST `/api/llm/test`；POST `/api/llm/explain`（revision与可选question）。

落子坐标左上角为 x0,y0：9 路是 A9，19 路是 A19。19 路右下角 T1 为 x18,y18。数字1黑2白，字母跳过 I。新对局和摆题的 size 支持 9/19，未传默认为 9；导入题按自己的 size 恢复。19 路可在棋盘内切换放大后滚动查看。
